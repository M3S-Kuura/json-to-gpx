# Json to GPX processor

Extracts GPS coordinates from gps json file, and converts it into a single .gpx file displaying the route.

### Setup:

Setup venv

```bash
python3 -m venv venv/
```

Source the environment

```bash
source venv/bin/activate
```

Launch the python script

```bash
python3 json_to_gpx.py input.json output.gpx
```
